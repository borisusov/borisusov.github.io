Статичний сайт DevOps-інженера як тест на S3.

Без серверів, без рантайму, без сюрпризів. HTML/CSS/JS у бакеті, публічний website endpoint, інфраструктура описана в Terraform. Це не лендінг «про себе» — це демонстрація, як я виконую тестове завдання: швидко, відтворювано, з інструкцією для деплою.

Робочий стек

Те, чим зазвичай закриваю тестові та продакшн-завдання.

  • Cloud

    AWS (S3, CloudFront, IAM, VPC, ECS/EKS), GCP basics, cost-aware дизайни.

  • IaC

    Terraform модулі, remote state, plan у CI, без ручних кліків у консолі.

  • CI/CD

    GitHub Actions / GitLab CI: lint, test, artifact, sync на S3, smoke-check URL.

  • Containers

    Docker, Kubernetes, Helm. Статика тут навмисно без контейнерів — менше рухомих частин.

  • Observability

    Логи доступу S3, метрики 4xx/5xx, алерти на broken deploy, health на index.html.

  • Security

    Least-privilege IAM, bucket policy лише на GetObject, блокування public ACL, HTTPS через CloudFront (опційно).

Що робить цей репозиторій

Мінімальний, але повний контур для тестового S3-сайту.

  1. 01

    Статика в site/

    Один index, error-сторінка, CSS, легкий JS. Жодних білдерів — aws s3 sync достатньо.

  2. 02

    Terraform у infra/

    Бакет, website hosting, public GetObject, outputs з URL. Ідемпотентний apply.

  3. 03

    Скрипт scripts/deploy.sh

    Apply + sync + інвалідація cache (якщо є CloudFront). Один вхід для людини і для CI.

Архітектура деплою

Прямий S3 website endpoint. CloudFront можна додати другим кроком.

Git  →  scripts/deploy.sh
          ├─ terraform apply   →  S3 bucket (website)
          └─ aws s3 sync site/ →  index.html + assets
                                  └─ http://<bucket>.s3-website.<region>.amazonaws.com
Деплой локально
  1. Експортуй AWS_PROFILE / ключі з правами на S3 і IAM.
  2. cd infra && terraform init && terraform apply
  3. ./scripts/deploy.sh — заливає site/ у бакет.

Деталі — у README.md кореня репозиторію.

Готово до рев’ю

Це тестова сторінка. Після деплою URL з Terraform output можна віддати як доказ, що пайплайн живий.
